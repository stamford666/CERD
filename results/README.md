# Result receipts

Only participant-free aggregate receipts are published. Raw data, identifiers,
predictions, logs, and checkpoints are excluded.

## Current paper results

- [`abcd_current_binary_matched_v1.md`](abcd_current_binary_matched_v1.md):
  current strict binary ADHD endpoint and matched comparison.
- `abcd_current_binary_cerd_v1.json`: CERD validation selection and formal
  three-seed result.
- `abcd_current_binary_baselines_v1.json`: six matched baselines, including
  complete/incomplete subsets.
- `abcd_current_binary_component_ablation_v1.json`: matched full and
  incomplete-subset component controls.
- `cerd_three_seed_modality_audit_v2.json`: ADNI/ABCD strict-removal relevance,
  accuracy-drop shares, and correspondence.
- [`adni_matched_updated_cerd_v4.md`](adni_matched_updated_cerd_v4.md): current
  ADNI CN/MCI/AD comparison.

Every aggregate is an arithmetic three-seed mean ± sample standard deviation,
not a probability ensemble.

Earlier endpoint receipts remain as archival provenance only and are not used
by the current manuscript tables.

# Attribution and third-party components

CERD's sparse-MoE backbone and parts of its data interface were developed from
the public Flex-MoE implementation:

- Sukwon Yun et al., *Flex-MoE: Modeling Arbitrary Modality Combination via
  the Flexible Mixture-of-Experts*, NeurIPS 2024.
- <https://github.com/UNITES-Lab/Flex-MoE>

The sparse expert implementation depends on FastMoE:

- <https://github.com/laekov/fastmoe>

Please consult the upstream projects for their authorship, citation, and
redistribution terms. This repository does not include either project's Git
history, datasets, checkpoints, or generated results.
